# Manual test script

For a person, or an agent driving a browser. Run `deno task dev` and open the local URL with `?seed=121`. Before each section, reload. To read logical state, use `game.state` in the console. To read what has played, use the panel beside the grid, including the `#live` text, the Inventory list and the Recipes list, or look at the marker.

Keys: arrows move, `E` gathers on the current cell, and `1`–`9` craft the recipe with that number in the Recipes list.

**Promotion rule:** a bug found by hand or by an agent becomes a permanent test in `core/` before it is fixed, unless it truly lives in `game/`, in which case add a step here.
